# 异常日常事务所

> 有人把全城的明天洗缩水了。今晚，你是唯一没有下班的调查员。

中文、免费、无依赖的微型叙事网页游戏原型。约 10 分钟完成，三个委托、三件线索、两种普通结局和一个隐藏结局。MIT 开源许可，无账号、无后端、无外部 API、无分析追踪和付费资源。

## 开始

需要 Python 3（运行静态服务）；测试需要 Node.js 20+。无需 `npm install`。

```sh
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
npm test
npm run check
```

不要直接双击 index.html：浏览器对 file:// 下的 ES 模块可能有限制。GitHub Pages 可直接运行，不需要构建。

## 世界与玩法

虚构的城市每天在 25:00 多出一个没有写在日历上的小时。玩家在失物招领处、末班电梯和月亮洗衣店选择保留或放手，拼出一句给自己的暗号，决定城市明天的模样。

- 委托可任意顺序进行；选项一经归档不能在同一轮修改，重置后可重玩。
- 收集三字线索后打开最终档案；无输入次数或时间限制，也有提示。
- 隐藏结局需要在三份委托中同时出现保留和放手。
- 完成一轮后可重读或切换已解锁的结局；重置会清除这一轮进度。
- 每份委托配一件完全可跳过的现实小事，不要求出门、地理位置、摄像头或上传证明。

## GitHub Pages 部署

仓库：`coder999o/anomalous-everyday`。静态页面部署使用 main 分支根目录。

在仓库 Settings → Pages → Deploy from a branch，选择 main / (root)。部署完成后的实际地址以 GitHub Pages 设置页为准。

公开仓库的 Pages 静态托管通常可以使用 GitHub 免费额度，受 GitHub 当时条款及用量限制约束。游戏本身没有收费服务；没有域名费用或服务端费用。不要把凭据、个人信息或进度文件提交到仓库。

## 维护

- `engine.js`：世界观、委托、结局与纯状态逻辑。
- `app.js`：页面渲染和交互。
- `storage.js`：IndexedDB 事务、旧存档只读导入、跨标签页冲突与重置隔离。
- `style.css`：移动端单列、桌面三列、低动画偏好与焦点样式。
- `tests/engine.test.js`：状态、门槛、所有分支组合、存档测试。
- `dist/`：静态预览副本，用 `npm run build` 更新。GitHub Pages 根目录部署不依赖它。
- `.openai/hosting.json`：仅本地预览配置，无已注册站点身份。

改变逻辑后运行 `npm test && npm run check && npm run build`，再按 QA.md 手测。故事数据由维护者直接写入代码；目前不支持玩家投稿或不可信 HTML 内容。增加新案例应升级存档格式并增加迁移，不应直接覆盖用户已有进度。

### 隐私与已知边界

进度只放在当前浏览器 IndexedDB，不能跨设备同步，清理浏览器数据会丢失；无法启用 IndexedDB 时明确提示仅当前页面临时游玩，不写共享存档。没有服务端可以恢复进度。联网只用于获取页面与同源静态文件；没有离线缓存服务工作线程。浏览器前进/后退不是游戏内导航，使用页面上的返回按钮。页面支持键盘和响应式布局，但尚未做手机实机和屏幕阅读器全面验收。

后续方向：案件 0002《影子申请离职》，继续纯静态内容，不加入账号或付费依赖。是否发布、更新排期和持续监测由项目负责人单独安排；本包不包含自动维护服务。



## v0.1.1 存档修复

更新后请刷新所有游戏标签页，确保旧页面不再运行 v0.1.0。

- 每次修改都在同一 IndexedDB object store 的 readwrite 事务内读取最新记录、校验并写入，浏览器负责串行化竞争事务。不是依赖 localStorage 的读后写，也不依赖消息到达先后。
- 同一轮的不同委托可以累积；同一委托先提交的选择保留，后来的旧选择会被拒绝并显示同步提示。
- 重置生成新一轮标记。旧轮次的选择/结局一律拒绝；过期的重置确认和结局选择也不会覆盖别人刚保存的进度。
- 首次初始化时在事务内只读导入 v1 localStorage 中的有效进度和结局。原副本保留，不删除、不改写；以后不重复导入，旧版本页面不能覆盖新数据库。**首次导入之后，未刷新的旧版本页面所做的新选择不会自动并入新版，请刷新旧页再继续。**
- BroadcastChannel 和页面重新获焦只负责及时刷新界面，正确性来自数据库事务。缺少 BroadcastChannel 时，提交仍会校验最新记录，但背景页面可能要重新获焦或刷新才显示变化。
- IndexedDB 初始化不可用时仅允许当前页内存模式，明确告知不能可靠保存。已启用数据库后写入失败会显示失败，不偷偷回退成一次“成功保存”。
- 无后端仍意味着浏览器清理、隐私窗口结束、磁盘故障等可以使本机数据丢失。跨设备和跨浏览器不会同步。

测试：`npm test` 包括状态和冲突规则；静态服务下打开 `tests/browser.html`，点击运行，使用随机测试数据库并在完成后删除测试数据库，完全不读取真实游戏存档。
